# Personal Portfolio - Mostafa Karam

My personal data analyst portfolio website. Built with plain HTML, CSS, and JavaScript (no frameworks), and hosted on GitHub Pages.

**Live site:** https://mostafakaram893.github.io/Portfolio/

## Contents

- Featured data analytics projects (Power BI dashboards, SQL database design)
- About, skills, and certifications
- Downloadable CV and contact links

## Repository Structure

```text
Portfolio/
│
├── index.html       # Single-page site
├── style.css        # Styling and responsive layout
├── script.js        # Interactions and dynamic content
└── assets/          # Images and certificates
```

## Running Locally

Open `index.html` in a browser, or serve the folder with any static server, for example:

```bash
python -m http.server 8000
```
